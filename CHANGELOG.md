# Changelog

## 1.5.0 — 2026-10-04

- Selecció de les preguntes essencials: 80 als temes 1, 2 i 3, i 78 al tema 4.
- Prioritat als conceptes, diagnosi i trets distintius, reduint repeticions i detalls secundaris.
- Dues preguntes complementàries per fitxa, mantenint les fitxes d’estudi completes i les referències originals.
- Recompte del selector, claus de memòria cau i documentació actualitzats. Selecció detallada a CURATION.md.
